# Bai55Inventory

1. Chạy `Database/ScriptDB.sql` trong SSMS để tạo `InventoryDB`.
2. Sửa `App.config` nếu SQL Server không dùng instance mặc định.
3. Mở `Bai55Inventory.sln` bằng Visual Studio 2022, build và nhấn F5.

Các lớp được chia thành DTO, DAL, BUS, GUI. Dữ liệu SQL được truyền bằng tham số.
